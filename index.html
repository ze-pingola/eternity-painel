Stack proposta

O que eu usaria pra construir de verdade
Bot — discord.js v14 (Node)

Slash commands, embeds, botões, threads. 24/7.

Backend — NestJS + Webhooks

Liga bot, painel e pagamentos. Multi-tenant.

Painel — React + este design

Login via OAuth2 do Discord.

Banco — PostgreSQL + Redis

Dados + fila de entrega.

Pagamento — Mercado Pago / Efí (split)

PIX com webhook + divisão automática.

Com split payment, nenhuma parte do fluxo segura dinheiro de terceiros. Engenharia limpa, risco jurídico mínimo.
